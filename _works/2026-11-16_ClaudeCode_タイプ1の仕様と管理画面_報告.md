## 0. 先に結論

- タイプ1の本体は**管理画面**。メイン画面は、管理画面で組んだものの結果として動く。
- ③は**店のHPの言葉そのもの**を選択肢にする。内部では「小分類」に当てる。

- ⑥から先は、店が＋で足したときだけ生まれる。深さはそろえない。
- この先の直しは**データの手入れ**が中心。ユーザーがURLを当ててレポートし、Claude Code が表を直す。2〜3回で仕上げる見込み。

## 3. 経緯（短く）

2. ユーザーの指摘：管理機能が本体。選択式は「選ぶ→次の問い→選ぶ」がUIの動き。道幅・角地はロケーションで、選択の幹ではない。
3. ユーザーの構想で管理画面を作り直した。③＝HPから拾った業務内容、並べ替え・直す・足す、URLの読み込みでいつでも初期状態に戻す。
4. ④⑤が弱い（③は具体的なのに、④⑤は汎用の土地の選択肢で、選択の続きに見えない）。ユーザーと Claude Code の見方：短い時間で④⑤を積み上げるのは、Fable でも難しい。
5. ユーザーの方針：④⑤は店の表現ではない。小分類と押したボタンから発想する選択肢で、重なり・行き来は問題ない。データは並べ替えて確かめやすい平らな表に。
6. 候補の表と、文脈で選ぶ仕組みを作った。管理画面は③④⑤の3列で、⑤の先は右へ広がる（ユーザー案）。返す文の初期値を入れた。
7. ③の抽出を強くした（最低3つ、問い合わせの出口は必ず出す）。

## 4. 仕様

### ③（業務内容）
- 店のHPのトップを読み、メニューのリンクと本文の「主な業務内容」などの箇条から、業務の見出しを全部拾う（AIなし。server/shop/read.js の menu、/api/shopmenu）。
- 外のサービスに飛ぶ物件検索のリンクは、「売買物件」「賃貸物件」のような短い見出しだけ拾う。個々の物件や宣伝（値段・面積・番号・「！」付き）は外す。
- 拾った見出しを小分類に当てる。同じ小分類が重なれば、短い見出しを一つだけ残す。「事業内容」のような大枠の見出しは、売却＋土地活用＋相続の3つを合わせる。
- **最低3つ**：トップで3つに届かなければ、会社概要とサイトマップのページも読み足す。それでも足りなければ、よく出る小分類（売却→相続→買取→査定→空き家）から補い、管理画面に「補い」の印を出す。
- 店は、並べ替え・直す・消す・足すができる。名前を直した選択肢は、その先が空白に戻る。

### ④⑤（文脈で選ぶ）
- 候補の表から、③の小分類と、押したボタンの言葉で選ぶ（docs/js/type1.js の t1Next）。
- 同じ小分類の行は「重み」の順に並べる。
- 「前の言葉」がある行は、押した言葉に当たったときだけ出して一つ上げる。
- 別の小分類の行でも、前の言葉が当たれば一つ下げて混ぜる（行き来）。
- 一度選んだものは出さない。前の段で見せて選ばれなかったものは二つ下げる。こうすると、⑤には④の言葉に反応した新しい候補が上に来る。
- 一つの段に出す候補は5つまで。④⑤は土地では変わらない。

例：③「買取サービス」→④「買取だと値段はどのくらい下がるか」→⑤の上位に「仲介で売った場合との差」「下がる分で、何をしなくてよくなるか」。

### ⑥から先
- ⑤の選択肢を選んで＋を押すと⑥の列が生まれ、右へ広がる。⑥から先は店が書く。

### 返す文
- ボタンごとに一つ。客がそのボタンを押したときに返す。
- 初期の文は、④⑤なら候補の表の「返す文」の列、③なら小分類ごとの文（reply3）。店が直せば店の文が優先される。
- 形は「受け（何の話か）＋要点（数字の穴）＋次への橋」で1〜2文。
- {目安額} {駅距離} などの穴は土地の値で埋まる。値のない穴を含む一文は落とす。

### 問い合わせ
- ③から先のどの段にも「ここまでの情報で問い合わせを送る」を必ず付ける。③が0のおかしなサイトでも、行き止まりにしない（ユーザーの言う「奥の手」）。
- 子のない選択肢を選んだ先は、問い合わせだけ。

### 保存
- 店の組み立ては localStorage「reType1」（v:3）。

## 6. Fable の初期設定（type1_defaults.json v0.6）の扱い

- 使っている：土地の扱い（landOf：カテゴリー・条件札・穴の値）、締めの一文（rules.close）。
- 使わなくなった：options（14の土地の選択肢）と、その next・数字入りの返事、sets（業態×カテゴリー）、firstMark・grey。④⑤を候補の表で選ぶ形にしたため。数字入りの返事の文は、返す文を厚くするときの材料として残る。

## 7. この先

- ユーザーが管理画面で③〜⑤を確かめ（メイン画面も並行）、レポートする。
- Claude Code は、レポートを「どの表のどの行か」に置き換えて直す（手がかりの言葉、小分類を分けるか、候補の行、返す文）。仕組みには手を出さない。
- 1回のミッションでURLを10〜20件まとめて渡してもらい、Claude Code が一括で③④⑤を出して怪しい店に印を付ける案を、ユーザーに出してある。
- 気づき済みの直す候補：「一戸建て（新築・中古）」が「新築」に引かれて開発・分譲・建築に入る。
