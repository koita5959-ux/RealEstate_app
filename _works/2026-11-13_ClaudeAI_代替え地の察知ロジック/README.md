# 代替え提案 察知ロジック 試作 v0.1（ステップ①：API不使用）

## 目的
客の発話の流れから「今の土地を手放して、郊外で広い土地を」という代替え提案を出してよい局面かどうかを、**Claude API に投げずにプログラムだけで**どこまで判定できるか試す。

対象は土地の話に限る。中古住宅は築20年を超えれば土地評価が基本になるので、建物にこだわらない状況であれば対象に含める。

## 判定の三層
| 層 | 内容 |
|---|---|
| 1. 適格ゲート | 土地のみ／築20年超／「建物にこだわらない」「建て替え」の発言 → 対象。築浅でこだわりあり → **対象外** |
| 2. 兆しの積算 | 手放す系 +2、広さ系 +2、郊外容認系 +1、逆向き（駅近・地元を離れたくない・学区）-4。同じカテゴリは最大2件まで数える |
| 3. 発動判定 | 手放す系＋（広さ系 or 郊外系）がそろい、4点以上で逆向きなし → **発動**。片側だけ → **保留**。逆向きあり／兆しなし → **不発**。発動は会話中1回だけ |

広さ系の兆しには目的タグ（住宅地_広さ／住宅地_庭／住宅地_二世帯／農地／事業用）が付く。これが、次のステップで国交省データを探すときの条件になる。

## 実行
```
python3 run_test.py
```

## 結果（v0.1）
- **基本ケース 15/15**：はっきりした言い方なら、ルールだけで確実に判定できる
- **難ケース 1/6**：遠回しな言い方は取れない（1件当たったのは偶然）

### 途中で直したこと（辞書の穴）
- 「売**って**」を拾えていなかった → 活用形を追加
- 「庭**の**ある家」を拾えていなかった → 追加
- 否定判定が広すぎて「庭を広くでき**ない**かな」まで打ち消していた → 意思の否定（つもり／気／予定＋ない）に絞り、手放す系・郊外系だけに適用

### ルールの限界（難ケースの外れ方）
| ケース | 外れ方 | 危険度 |
|---|---|---|
| 子どもが走り回れる／のびのび／大型犬 | 広さの欲求を言い換えで表すと拾えない → 保留・不発 | 低（機会を逃すだけ） |
| 「駅近**じゃなくても**いい」 | 逆向きの兆しと取り違え → 不発 | **中**（いちばん合う客を逃す） |
| 「**友人が**郊外に住み替えた」 | 他人の話を本人の兆しとして数える → 保留 | 低（保留止まりで発動はしない） |

## わかったこと → ステップ②への橋渡し
1. **ルールは「発動」側を固く作れる。** 誤発動（勧めすぎ）は客優先の芯を傷つけるが、ルールでは基本・難ともに誤発動はゼロだった。
2. **外れはすべて「保留・不発」側に出る。** つまり、プログラムが迷うのは「保留」のときだけ。
3. したがってステップ②では、**API に判断を任せるのは「保留」の局面だけ**にする。それも、毎ターンの通常応答に目印を返させるついでにやる。明確な発動・対象外はプログラムだけで決まるので、API の判断に頼る範囲を最小にできる。
