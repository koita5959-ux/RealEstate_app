## 2. 実装でやること（配線）

### 2-1 `/sample/` での配信と地区名

- 配信のしかたは HP制作企画書（11-14）3章・9章のとおり：api が `?r=` を見て、`index.html` の印を書き換えて返す。`img/`・`style.css` は相対パスなので、**`/sample` は `/sample/` へ転送**する（末尾の `/` がないと画像が切れる）
- `{{REGION}}` は地区一覧.csv の「代表の市」。差し込む前に HTML エスケープする
- 印は5か所（`<title>`／`meta description`／FV／業務案内の導入文／会社概要の所在地）。**`r` がない・一覧にないとき**の置き換え：

| 場所 | `r` なしのとき |
|---|---|
| FV の `<span class="region" data-region-line>` | **span ごと消す**（「地域ほか」のような半端な行を出さない） |
| `<title>`・meta・業務案内の導入文 | `{{REGION}}` →「地域」（「地域の不動産相談」「地域を中心に」で自然に読める） |
| 会社概要の所在地 | セルの中身を「（サンプルのため架空）」だけにする |

### 2-2 `#bot-slot` へのボットの組み込み

- タイプ2・3のどちらを入れるか（両方か）は、HP制作企画書10章の未決のまま。ユーザーと決める
- 枠は空のときだけ「ここにAI相談ボットが入ります」が出る（`:empty::before`）。中身を入れれば消えるので、CSS を触る必要はない
- 地図の最初の位置は地区の代表の市（HP制作企画書3章）

### 2-3 問い合わせ（`form.inquiry[data-inquiry]`）

- ページ最後のフォームと、セッションの締めに出すフォームは**同じ部品**。締めでは、この `form` を複製して会話の続きに出す
- 送信：`type="button"` のクリックで api へ送る。送信先は弊社、中身は入力内容＋セッション番号＋地区ID（＋送り先の印 `k`、11-14 の依頼書）
- 送信後：`.inquiry-done` の `hidden` を外し、［OK］で戻す
- 注記（「この見本ではお問い合わせは開発元へ届きます…」）はすでにHTMLにある

### 2-4 HP読み取りから `#bot` を外す（`data-read="skip"`）

この区画はボット自体の説明なので、店の材料として読ませない。これで「ボットの解説をHPに書けない」という課題が外れる。

- 場所：`server/shop/read.js` の `parse()`。`script|style|noscript` を除くところで、あわせて `data-read="skip"` の付いた要素を中身ごと除く。例：
  ```js
  html = html.replace(/<(section|div)\b[^>]*\bdata-read=["']skip["'][^>]*>[\s\S]*?<\/\1>/gi, ' ');
  ```
  （`#bot` の中に `section` の入れ子はない。ボットを組み込んだあとも入れ子にならないよう注意。入れ子になるなら、印のコメント `<!--read:skip-->…<!--/read:skip-->` に切り替える）
- 画像の `alt`（「売却を検討する一戸建てのイメージ」など）は今の仕組みで材料に混ざる。害はないので、そのままでよい
- 確認：読み取りの結果に「24時間いつでも」「公開データをもとに」が出てこないこと
- 試験台：`_works/2026-11-15_ClaudeAI_確認用_サンプルHP_尾張23-1.html` を raw.githack で公開URLにしたもの（https://raw.githack.com/koita5959-ux/RealEstate_app/main/_works/2026-11-15_ClaudeAI_確認用_サンプルHP_尾張23-1.html ）を管理画面の指定URLに入れて読み取る。除外を入れる前と後で比べ、あわせて免許番号・担当地域・買取の3項目が拾えるかを見る
