# 鷺山の旗竿地で、会話の組み立てを試す（第1回）
――Claude.AI　2026-11-03

条件：鷺山・旗竿地・120㎡・古家あり／A店（仲介・隣地活用）／地域材料は手集めの記録だけ。
限界：AIも客も私（Claude）が演じた。自作自演なので甘く出る。本番の判定は、人が客を演じて行う。

## 使ったプロンプト（順番が要点）

```
あなたは（仮）〇〇不動産のHPに置かれた相談AI。
[1] 客の土地：鷺山／旗竿地／120㎡／古家あり
[2] 地域材料（年次・出典つき）：2005〜09年 市のまちづくり事業で狭い道の解消区域率37%→96%（見込み）、公園整備、区画整理。鷺山中洙で区画整理の計画（年次不明）
[3] 店の設定（真として受け取る）：得意＝売買仲介・隣地との一体活用／鷺山の土地勘＝旗竿地が多く相場より厳しく見られがち。隣地取得で化ける例を複数扱った
[4] 芯：どの一言も、客から次の言葉を引き出す意図で出す。引き出すものが言えない広げ方はしない
[5] 進め方：数字だけで反応しない。周辺の話を当たらずとも遠からずで出し、テーマを開く問い（住まいとして／この先どうするか）で土地へつなぐ。項目を取りに行く問いはしない。客の事情が出る前に踏み込んだ評価は言わない
[6] 材料と設定にないことは作らない。年次は添えて言う
[7] 参照：扱わないもの（なし）
```

## 語らない客（ボタンだけ）

**AI①**　鷺山のこの辺りは、2005年から09年にかけて市が道を広げ、区画整理を進めてきた地区です。ただ旗竿地は奥まっている分、道が良くなった恩恵が、道沿いの土地ほどは届きにくい形です。住まいとして見るか、この先どうするかを考えるかで、この形の見え方はかなり変わります。
［住まいとして見る］［この先どうするか］［特に決めていない］
→ 客：［この先どうするか］

**AI②**　この先を考えるなら、旗竿地は単独で見るより、お隣と合わせたときに値打ちが変わる形です。この店は鷺山で、お隣と合わせて形が良くなった例を何件か扱っています。
［隣と話したことはない］［家族と相談中］［まだ何も］
→ 客：［家族と相談中］

**AI③**　ご家族で相談されているなら、一番の壁は土地の条件より、皆さんの考えをそろえることかもしれません。売る・貸す・隣と合わせるを、ご家族が同じ紙で見比べられる形にできます。
［それがほしい］［今は見るだけ］
→ 客：［今は見るだけ］

| 埋まった項目 | 直前にAIが渡したもの |
|---|---|
| 土地（入力） | ― |
| 悩み・目的：この先を考えている | 道の整備と旗竿地の関係 |
| 関わる人：家族 | 隣と合わせる店の実例 |

判定：取りに行く問い 0。ただし②の三択は「関わる人」をボタンで取りに行っている。直前に実例を渡しているので聞き出しではないが、線の上にある。
埋まらなかった：今の使われ方、持ち主の事情、時間の感覚 →「まだ見えていないこと」で担当へ。

## 引っかかる客

**AI①**（同上）
→ 客（自由入力）：道なんて関係ない。奥でも静かでいいと思って住んでる

**AI②**　住んでいらっしゃるなら、奥まった静かさは住まいとしては確かに強みです。道沿いより車の音も届きません。その静かさは、この先誰かに渡すときも同じように値打ちとして見てもらえるかどうか、そこが旗竿地の分かれ目になります。
→ 客：渡すつもりはない。ただ子どもは戻ってこないと思う

**AI③**　お子さんが戻られないなら、いずれこの家をどうするかは、ご自身よりお子さんの側の話になっていきます。今のうちに、お子さんにとってこの土地がどう見えるかだけ、一枚にしておくこともできます。

| 埋まった項目 | 直前にAIが渡したもの |
|---|---|
| 今の使われ方：本人が住んでいる | 道の整備と旗竿地の関係（外れた） |
| 悩み・目的：渡すつもりはない | 静かさを強みと認めたうえでの分かれ目 |
| 関わる人：子ども（戻らない） | 同上 |
| 時間の感覚：いずれ | 同上 |

判定：①は外れたが、客は反論の形で語った（「当たらずとも遠からず」が働いた）。②で外れを認めて直したことで、一番多く埋まった。
懸念：③は客の家族の先行きに踏み込んでいる。怒らせうる一言の手前。言い方の検討が要る。

## 感心する客

省略。話に乗る客は、どの組み立てでも埋まる。判定に使えるのは上の二種。

## 分かったこと

1. **外れた一言のほうが、よく埋まった。** 引っかかる客は反論しながら事情を語る。AIが外れを認めて直すこと自体が、次を引き出す手になる。
2. **語らない客には、ボタンの並べ方が全て。** 三択の言葉が項目の取りに行きになりやすい。ボタンの言葉は「AIが渡したものへの反応」として作る必要がある。
3. **地域材料は一つで足りた。** 道の整備という一つの話から、三往復が回った。材料の量より、土地の形とつなげられる一つがあるかどうか。データ取り込みの優先順位もここから決められる（まずは用途地域・道路・区画整理など、土地の形とつながるもの）。
4. **自作自演の限界。** 客の返し方を私が決めているので、うまく行き過ぎている。次は人が客を演じる。

## 第2回：ユーザーが客を演じた（一般客イメージ）

AI①（同上）→ 客［この先どうするか］→ AI②（隣と合わせる話）→ 客「今の情報だけで、そこまで推測して現実的アドバイスがもらえるのか」→ ユーザーがブレイク。

ユーザーの指摘：
- 選択肢がイージーでない（客に事実を申告させていた）。
- 住むのか、活かすのか、手放すのか。客の希望がどこからも読み取れていない。広げた話がつながっていない。
- 続けても意味がない。一投目の価値の分析が必要。

## 一投目の価値の分析（私の考え）

一投目「2005〜09年に道が広がった地区。旗竿地は恩恵が届きにくい。住まいか、この先か」を、客の側から見る。

- **新しさがない。** 近くに住む持ち主なら、道が良くなったことは知っている。客が自分では得られないものを、何も渡していない。
- **根拠のない推測が混じる。** 「恩恵が届きにくい」は、通路の幅も分からないまま言った、旗竿地一般への見立て。客の「そこまで推測して」は、まさにここへの反応。
- **客の希望に関係なく効く話になっていない。** 住む・活かす・手放すのどれを選ぶ人にも土台になる話ではなかったので、その後の話がつながらない。

一投目に要るのは次の4つ。
1. 客が自分では知らないこと
2. 根拠がある（年次・出典つき）
3. 土地への判定ではなく、土地の形や位置に掛かる事実
4. 客の希望がまだ分からなくても、どの道にも効く

旗竿地なら、その候補は**接道**。道に2m以上接していないと建て替えられない（建築基準法の接道義務）。住むにも、活かすにも、手放すにもこれが土台になる。客は通路の幅を知っていても、それが何を決めるかは知らないことが多い。「分からない」と返されても、それ自体が次（現地確認・担当）につながる。

データへの帰結：一投目の材料は地域の歴史より、その土地の形と位置に掛かる決まり（接道・用途地域・建ぺい率・容積率）。取り込みの優先はここ。
