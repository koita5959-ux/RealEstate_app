## 1. このページは何か

零細の仲介不動産会社（社長と数人の店）に、「御社のホームページに、不動産向けチャットボットを載せませんか」と提案する広告ページです。

- **売り手**：Webの開発元（不動産会社ではありません）。文中では `{{DEVELOPER}}` と書きます。
- **読み手**：不動産会社の社長・担当者。メールで案内を受けて開きます。ITに詳しくない人が多く、スマホで見る人も多い。
- **どこから来るか**：架空の不動産会社のサンプルサイト「AIボット不動産」のヘッダーにあるボタンから、このページが開きます。サンプルサイトには実際に動くチャットボットが載っています。
- **このページの役目**：サンプルサイトが「何を売るための見本なのか」を、一目で分かるようにすること。読んだ人が次にすることは二つだけです。
  1. サンプルサイトに戻って、チャットボットを触る
  2. 開発元に問い合わせる

読み手は「サンプルを触る前」にも「触ったあと」にも来ます。どちらでも通じるように書いてください。

## 2. いちばん伝えたいこと（広告の芯）

> **ホームページは一方通行。問い合わせが来るまで、訪問者が何を考えているかは分からない。このチャットボットは、問い合わせの「手前」を受け止める。**

読み手の不動産会社には、次の三つの得があります。この三つを、必ずページの上のほうで見せてください。

1. **問い合わせに至らなくても、訪問者の関心が店に残る。**（どの地域の、どんな相談が来ているか）
2. **お客さん自身の、ぼんやりした考えが整理される。**（地図で場所を示し、選んだり話したりするうちに）
3. **整理された内容が添えられて、問い合わせが届く。**（電話の前に、相談の中身が分かる）

「お気軽にお問い合わせください」と書いて待つだけのHPとの違い、という対比が使えます。

### キャッチコピーのたたき台（もっと良い案を出してください）

- 問い合わせの「手前」を、取りこぼさない。
- 御社のホームページは、お客さんの話を聞いていますか。
- 「お気軽にお問い合わせください」の、その前に。

## 3. ページの組み立て

順番は変えてかまいません。ただし ①〜③ は最初の2画面以内に入れてください。

| # | 区画 | 中身 |
|---|---|---|
| ① | ファーストビュー | キャッチコピー、一言の説明、ボタン二つ（「サンプルで試す」「問い合わせる」）。上に小さく「サンプルサイト『AIボット不動産』に載っているチャットボットのご案内です」 |
| ② | 今のHPの困りごと | 物件紹介や検索を載せても一方通行。訪問者の希望は、問い合わせを待つしかない |
| ③ | 三つの得 | 2章の 1〜3。アイコンか短い図で |
| ④ | 動き方（3ステップ） | 地図で場所を示す → 選ぶ・話す → 内容を添えて問い合わせ。**どのタイプも、まず場所の確認から始まる**ことを見せる |
| ⑤ | 三つのタイプ | 4章の表。比べやすく |
| ⑥ | 導入の形 | 5章の三つ |
| ⑦ | 費用の考え方 | 6章 |
| ⑧ | よくある質問 | 7章。3〜5問 |
| ⑨ | 締め | ボタン二つをもう一度。開発元の名前 |

長さの目安：スマホで縦に6〜8画面。読ませるより、見出しと図で分かるページにしてください。

## 4. 三つのタイプ（事実。ここは変えないでください）

どのタイプも、**地図で場所を確認するところから始まり、最後は「店への問い合わせ」で終わります。**

| | タイプ1　選んで進む | タイプ2　自由に話す | タイプ3　話しながら案内する |
|---|---|---|---|
| 進み方 | ボタンを選ぶだけ | 場所の確認のあと、自由に書いて話す | 書いて話す＋店が用意した選択肢 |
| 答えるのは | プログラム（AIを使わない） | AI | AI |
| AIの契約 | **いらない** | いる | いる |
| AIの利用料 | **かからない** | 使った分だけ | 使った分だけ |
| 店ができること | HPの業務内容から選択肢が自動で入る。店が直せる | 話の進め方を、お客さんに任せる | 次の質問と選択肢を用意し、店が聞きたい方向へ案内できる |
| 向く店 | まず費用をかけずに始めたい | お客さんの生の声を聞きたい | 相談の中身をそろえて受けたい |

- 呼び名（「選んで進む」など）は、もっと良い言い方があれば替えてかまいません。番号と中身は変えないでください。
- どのタイプも、共通のプログラムが動かします。HPの作りに合わせたプログラムの手直しも受けます。これは一文で入れてください。

## 5. 導入の形（原稿の二つの箇条を、一つにまとめました）

原稿には「導入にあたって」と「導入に向けた流れ」があり、中身が重なっています。読み手が迷うので、このページでは次の三つにまとめます。

| 形 | 中身 |
|---|---|
| A　今のHPに載せる | 今のホームページはそのまま。チャットボットを足す。別ページとして用意し、今のHPからつなぐ形もできる |
| B　今のHPを見直して載せる | 手直しとあわせて、問い合わせを目的にしたサイトに整える |
| C　新しく作る | チャットボットを中心に、ホームページを一から作る |

どの形でも、お店の事情に合わせて費用を抑える、という一文を添えてください。

## 6. 費用の書き方

- 金額は書きません。「打ち合わせのあと、費用を含めてご提案します」と書きます。
- 「費用を抑えること」が前提の商品だ、と伝えてください。
- タイプ1は「AIの契約がいらない・AIの利用料がかからない」と書きます。

## 7. よくある質問（たたき台）

- **今のホームページのままで使えますか。** → 使えます（5章のA）。
- **AIは間違えませんか。** → 土地の数字は、国の公開データとプログラムの計算で出し、出どころを付けて伝えます。AIの見立ては「担当が確かめます」とつないで、問い合わせに進めます。
- **AIを使わない形もありますか。** → あります（タイプ1）。
- **お客さんの問い合わせは、どこに届きますか。** → 御社に届きます。サンプルサイトでは、開発元に届きます。
- **費用はどのくらいですか。** → 6章のとおり。

## 8. 書いてはいけないこと（必ず守ってください）

広告を強くしても、次は書かないでください。うそになるか、まだ約束できないことです。

- **数字の実績**：「問い合わせ◯倍」「導入◯社」「満足度◯％」など。実績はまだありません。
- **お客様の声・導入事例**：作り話の感想、架空の会社名、架空の人物の言葉。
- **「ランニングコスト0円」「月額0円」「完全無料」**：タイプ1で言えるのは「AIの利用料がかからない」までです。
- **「AIは正確」「間違えない」「査定できる」**：このチャットボットは査定をするものではありません。
- **「買いたい人・借りたい人にも対応」と大きく書くこと**：今の中心は、土地や家を持っている人の相談（売る・活かす・相続・空き家）です。主役はそちらにしてください。探す人については「地域の指定から始める形も、ご相談ください」程度にとどめます。
- **期限であおる言い方**：「今だけ」「先着◯社」。
- 実在の会社名・ロゴ・人物。

## 9. 言葉づかい

- 読み手は不動産の玄人で、ITの素人です。不動産の言葉はそのまま、ITの言葉はやさしく。
- 「ソリューション」「DX」「コンバージョン」「リード獲得」などのカタカナ語は使わない。
- 「チャットボット」は使ってよい言葉です。タイプ1はAIではないので、商品全体を「AIチャットボット」と呼ばず、「不動産向けチャットボット」と呼びます。
- 一文を短く。言い切る。「〜させていただきます」を重ねない。
- 売り手は「弊社」ではなく `{{DEVELOPER}}`、読み手は「御社」。

## 10. 見た目

- サンプルサイトと同じ色を土台にします。**同じ一続きの案内に見えること、ただし不動産会社のページではなく開発元の広告だと分かること**の両方がねらいです。
  - 深い紺 `#173B5C`（基調）／金茶 `#BC8A45`（差し色）／淡い灰青 `#F4F7F8`（区切りの背景）
  - 広告として目立たせるため、ボタンに使う強い色を一色足してかまいません。
- **一緒に渡す `index.html` と `style.css` は、サンプルサイトの実物です。** 色・余白・書体の参考にだけ使い、組み立てや文は写さないでください。サンプルサイトは「よくある不動産会社のHP」に見えるよう、わざと無難に作ってあります。このページは広告なので、見出しの大きさ、余白の取り方、ボタンの強さは、サンプルサイトより一段はっきりさせてください。食い違う所は、この企画書を優先します。
- 落ち着いた、信頼できる印象。派手なグラデーション、ネオン、「いかにもAI」な青紫の光は避けてください。
- スマホを先に考えた一列の組み。PCでは本文の幅を最大1100pxに。
- ボタンは大きく、親指で押せる大きさ（高さ48px以上）。
- 4章の表は、スマホでは横にあふれないよう、カードを縦に並べる形に切り替えてください。

## 11. 画像

- **画像に文字を入れないでください。**（日本語が崩れるため。文字はすべてHTMLで書きます）
- **チャットの画面を、画像で作らないでください。** 吹き出しや地図の模式図は、HTMLとCSSで組んでください。あとで本物の画面写真に差し替えます。差し替え用の枠を二つ用意してください（`img/shot_1.jpg`・`img/shot_2.jpg`、横4：縦3、今は淡い灰色の仮の絵）。
- 作ってほしい画像（すべてJPG、文字なし、実在の人物・ロゴなし）：

| ファイル | 中身 | 大きさ |
|---|---|---|
| `img/pr_fv.jpg` | ファーストビューの背景。日本の町の小さな不動産会社の店先か、相談カウンター。明るく、落ち着いた昼の光 | 横1920×縦1080ほど |
| `img/pr_oneway.jpg` | 「一方通行のHP」の場面。パソコンのHPを前に、電話が鳴るのを待つ店の人 | 横1200×縦900 |
| `img/pr_owner.jpg` | 土地や実家のことを、家でスマホを見ながら考えている持ち主（50〜60代） | 横1200×縦900 |
| `img/pr_reach.jpg` | 相談の内容が店に届き、店の人が内容を見てから電話をかける場面 | 横1200×縦900 |

- 人物は日本の町の、ふつうの人に見えること。モデルのような写真は避ける。
- 画像の合計は 1.5MB 以内が目安です。すべてに `alt` を付けてください。
- ページの下に小さく「画像はイメージです（AI生成）」と入れてください。

## 12. 技術の決まり

- ファイルは次の形で、一つのフォルダにまとめてください。

```
pr/
├─ index.html
├─ style.css
├─ README.md
└─ img/
```

- **JavaScript は使いません。** よくある質問の開け閉めは `<details>` で。
- 外部のフォント・CDN・外部の画像・解析タグは使いません。書体は端末のもの（`system-ui, "Hiragino Sans", "Yu Gothic", "Noto Sans JP", sans-serif`）。
- パスはすべて相対パス。
- `<head>` に `<meta name="robots" content="noindex">` を入れてください（メールで案内する相手だけに見せるページです）。
- 差し替え用の印を、次の名前でそのまま残してください。あとでプログラムが入れ替えます。

| 印 | 使う場所 |
|---|---|
| `{{DEVELOPER}}` | 開発元の名前（上の小さな帯、締め、フッター） |
| `{{SAMPLE_URL}}` | 「サンプルで試す」ボタンの行き先 |
| `{{CONTACT_URL}}` | 「問い合わせる」ボタンの行き先 |

- `README.md` に、使った色、印を置いた場所、画像の一覧、あなたが判断して変えた所（キャッチコピーを選んだ理由など）を書いてください。

## 付録A　元の原稿（発注者の趣旨説明。誤字だけ直しました）

**機能とHP作成・修正に伴う、不動産向けチャットボットの概要説明**

【趣旨・基本的考え方】
HPでは、掲示内容として物件紹介や検索機能を実装しても、基本的には一方通行で、お客さんのニーズ・希望は、問い合わせを受けることのみに頼らざるを得ません。不動産業向けチャットボットでは、問い合わせに至るまでの穴を埋めるため、お客様の入力・選択などから、実際にお問い合わせメールや電話に至らなくても、HPへの訪問者のニーズを獲得するところから始まります。チャットボットのガイド（導線）から、漠然としたニーズをお客様自身も鮮明にし、さらにはその整理から、HPの事業所への問い合わせもしやすくなる、という利点を想定しています。

【導入にあたって】
1. 既存HPのメンテナンスとチャットボットの実装
2. HPを、より問い合わせを目的としたサイトに作成する
3. Webアプリを活かしたHPの機能強化

これらを、クライアントのニーズにより、コストを抑えた導入スタイルとして、より具体的に商品化したものです。

【チャットボットの形態】
基本は、HPを指定したロケーション確認をキーに、セッションが始まります。対象が探す（借りたい・買いたい）であっても、場所・地域の特定から始まります。そのうえで「AI機能を利用する・利用しない」という選択での実装から、3種類の「チャットボット」をご提案しています。

1. HPにランニングコストが不要な選択型チャットボット（AI契約不要・ランニングコストがかからない仕様）
2. ロケーション確認以降、フリートークでお客様ニーズにおまかせするAIチャットボット
3. 次の質問を用意し、フリートーク＋選択肢を用意し、ある程度のサイト側ニーズに誘導できるAIチャットボット

いずれのタイプも汎用的プログラムがチャットボットをコントロールしますが、HP制作に合わせ、プログラムの修正も承る体制です。

【導入に向けた流れ】
1. 新規ホームページから構想する
2. 既存HPの見直しを踏まえ構想する
3. 既存ホームページとは連携を踏まえた別コンテンツを準備する

いずれの場合も、企画の想定では準備があり、お問い合わせいただければ多くのケースで対応が可能です。
※費用面については、コストを抑えることを前提に、打ち合わせの後、費用を含めたご提案をいたします。
