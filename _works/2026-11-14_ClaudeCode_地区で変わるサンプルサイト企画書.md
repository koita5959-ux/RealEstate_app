## 1. 何を作るか

不動産屋のサンプルサイト「遠見不動産」1つ。営業メールに付けるURLの印で、**開いた業者の地区の店**として見える。
サイトの中で、AIボットを客として試し、店に届くものを見て、自分の店に設定し直して、もう一度試せる。ボットの利点の説明もこの中に置く。

## 2. 土台：地区一覧

- 全国100地区（県はまたがない、県内2〜3、北海道4・島根1）
- 地区一覧.csv：地区ID・地区名・代表の市・入る市区町村（全部）・送るURL
- 逆引き.csv：全1,747市区町村 → 地区ID
- 割り当ては気象庁の細分区域のまとまりごと（境目のずれを防ぐため）
- **送るとき**：送り先の所在地（市区町村）を逆引きで引き、その地区のURLを付ける

## 3. URLの印で変わるもの

`…/sample/?r=23-1`（23-1＝愛知県 尾張）

| 変わる所 | 中身 |
|---|---|
| 看板（タイトル） | 「名古屋市・一宮市・春日井市・小牧市・半田市ほか 地域密着の遠見不動産」 |
| 地図の最初の位置 | 地区の代表の市あたり |
| 地域のページ | その地区の公開データ（標準地の値と動き・用途地域・駅など）から作った、地域密着の店が書きそうな文章 |
| ボットへ渡す材料 | 地区名と地域のページ（ボットはHPを材料に話すので、ここで具体が出る） |
| 記録 | どの地区のURLから来て、どこまで試したか |

- 地域のページは**送る前に地区ごとに1回作って保存**し、開いたときは保存したものを出すだけ（待たせない・崩れない・事前に確かめられる）
- 印がない／知らない印：地区名を出さない汎用の看板
- 全ページに「サンプル」の表示をはっきり出す（架空の店が実在の地域を名乗るため）

## 4. サイトの流れ（Claude.ai 企画書の①〜④をそのまま）

1. **客として試す**：遠見不動産（その地区の看板）のボットとセッション
2. **店に届いた記録を見る**：問い合わせで終わった瞬間に「店にはこう届きます」へ切り替わる（今の「利用状況」の画面が元）
3. **設定を変える**：指定HPを自社URLに替える（今の管理画面の読み取りがそのまま使える）
4. **もう一度、客として試す**：自社の店として話すボットになる

- 最後に立場を切り替える一文「ここまでがサンプルセッションです」と、その会話の中身から作った一言
- 問い合わせ欄は業者本人として書く。送信先は弊社、送る前に「この内容は開発元に届きます」と出す

## 5. 今あるものの流用

| 必要なもの | 今あるもの | 足すこと |
|---|---|---|
| サンプルHP | 見本「遠見不動産」（管理画面の初期値） | 実際のHPとして見えるページ（看板・地域のページ・会社案内程度） |
| ボット | タイプ2・3のメイン画面 | 印から地区名と地域のページを受け取る |
| 店に届く画面 | 利用状況（通った道・データシート・要所レポート） | 問い合わせ後の自動切り替え |
| 設定 | 管理画面（URL読み取り・ブラウザーごとの保存） | 業者向けに絞った入口 |
| 公開データ | 不動産情報ライブラリ・周りのデータ | 地区ごとの地域のページを作る仕組み |
| 記録 | 開発利用状況 | 地区IDの列と、地区ごとの集計 |
| メール送信 | なし | 弊社宛ての送信の仕組み |

## 6. 打ち合わせで決めたいこと

1. **見せるタイプ**：対話型（タイプ2）か AI型（タイプ3）か。Claude Code の推しはタイプ2（代替え地まで今いちばん仕上がっている）
2. **地域のページの中身と量**：どこまで書くか（標準地の値・駅・用途地域・暮らし向き）
3. **誰が開いたかの印**：地区の印だけか、送り先ごとの印（`&k=…`）も付けるか。付けると業者ごとの反応が分かるが、送り先ごとにURLが変わる
4. **締めの一言**：会話からAIで作るか（試用1回ごとに呼び出し＋1）、決まった文に差し込むか
5. **業者の受信箱へ届ける体験**（設定後の試用で自分宛てに届く）：最初は入れず、画面で見せて弊社宛て1本、が Claude.ai の推し
6. **ボットの利点の説明**をどこに置くか：試した後に読む説明として、②の画面の下か別ページか
7. **地区の分け方の見直し**：島しょ部（八丈・小笠原、奄美・種子島）などの残り

## 7. 作る順（案）

1. サンプルHPの骨組みと、印で看板・地図が変わるところ（AIなし・費用なし）
2. 1地区（尾張）の地域のページを作り、ボットに渡して話し方を確かめる（費用は事前に申告）
3. ①→②の切り替えと、弊社宛ての問い合わせ
4. ③④（自社URLで試す）
5. 100地区分の地域のページ
