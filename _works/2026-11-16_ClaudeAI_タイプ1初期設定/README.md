# タイプ1 初期設定の一式（たたき台 v0.3）

Claude.AI（Fable）より。2026-11-16。企画書 `_works/2026-11-16_ClaudeAI_タイプ1企画書.md` の3〜5章・7章を、中身にしたものです。決定ではありません。

| ファイル | 中身 |
|---|---|
| `defaults.json` | 業務内容4つ × カテゴリー4つの、④の選択肢・ボタン下の一行・返事の文・⑤の選択肢と返事 |
| `tryout.py` | 点検と、紙の上の試し。AIも通信も使わない。`python3 tryout.py` で、見本の土地3つ × 業務内容の組み合わせが出る |

## 入っているもの

- **選択肢 14個。** どれも、ボタンの下に数字の一行、選んだ後の返事（受け・土地の一文・中身・問い）、⑤の選択肢3つと返事を持ちます。
- **顔ぶれの表（`sets`）。** 業務内容 × カテゴリーごとに、④に出す選択肢と並び順。
- **決まり（`rules`）。** ④は5個まで、条件札が連れてくる選択肢、先頭の印、問い合わせのボタンを出す段、締めの文。

## 作りながら直した所（`tryout.py` で見つけた分）

1. **公開データのない土地で、返事が空になった。** 穴のある文は値がないと落とす決まりなので、穴だけの返事は中身がなくなります。どの選択肢にも、穴のない一行（`subPlain`）と一文（`plain`）を持たせ、⑤の返事にも穴のない文を一つ入れました。点検がこれを確かめます。検査項目「選ぶたびに、客が知らなかったことが一つ返る」を、データのない土地でも守るためです。
2. **条件札が連れてきた選択肢に、店の受けがなかった。** 仲介と相続・税を選んだ店でも、通路が2mない土地では「お隣と合わせる」が出ます。受けがなく「担当がうかがいます」に落ちていたので、業務内容によらない受け（`_`）を持たせました。
3. **先頭の印が、理由なしで付いていた。** 印は決まりが当たったときだけ付け、理由を添えます（「この土地なら、まず（通路が2mないため）」）。当たらなければ印なしで、並び順だけです。

4. **（v0.3）種類の違う標準地での計算に、但し書きを付けた。** 11-16 の Claude Code のテスト（岐阜市司町）で、商業地域の土地の目安が、最寄りの住宅地の標準地から計算されていました。タイプ2・3はAIが「比べた土地は住宅地なので」と補えますが、タイプ1には補い手がいません。標準地の種類が用途地域と違うときは、ボタンの下に「（近くの住宅地の値で）」、返事に但し書きの一文を必ず付けます（`rules.mismatch`、見本D）。

## 制度に触れている文（確かめ済みのもの）

| 文 | 確かめた先 |
|---|---|
| 受け継いだ土地の名義の変更（相続登記）は、今は義務 | 法務省（令和6年4月1日から義務化） |
| 家を壊すと、住宅が建っている土地向けの固定資産税の軽減がなくなる | 国土交通省・各市の案内（住宅用地の特例） |
| 道に2m以上接する／4m未満の道は下がる／畑は農地転用が先 | 今の `survey.js` の facts と同じ内容 |

数字（税率・期限・手数料の率）は、文に入れていません。変わったときに初期設定が古くなるためです。店と専門家が直す前提の初期値です。

## まだ粗い所

- 「車1台＝25㎡」は目安の決まりです。地域や形で変わります。
- 業務内容「開発」の住んでいる家（K1）は、選択肢が3つと薄いままです。
- ⑤は1段だけです。⑥から先は、店が＋で足す分として空けてあります。
- 買う側の人（持ち主でない人）のカテゴリーは入れていません（企画書13章の1）。
