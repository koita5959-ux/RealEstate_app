# サンプルHP（AIボット不動産）画像生成の依頼

- 作成：Claude.ai（構想立案プロジェクト）　2026-11-14
- 宛先：Claude Code（RealEstate_app）
- 土台：`_works/2026-11-14_ClaudeCode_AIボット不動産_HP制作企画書.md`（ページ構成・地区の切り替え）
- 決めたこと（ユーザー）：画像は **OpenAI の画像API** で作る。趣旨は「よくある不動産サイトに見えること」＝無難な仕上がり

---

## 1. 方針

- 地域性は FV のタイトル（地区名）だけに持たせる。**画像は全地区共通**で、地域を特定しない
- 「よくある不動産サイト」に見える定番の写真をそろえる。凝った絵・個性的な絵は狙わない
- **人物の顔・店舗の外観・看板・文字・ロゴ・有名な景色は入れない。** 架空の店が実在のスタッフや店舗を持っているように見せない（サンプルとして正直な線）。手元だけの写真はよい
- 画像の近くに小さく「画像はイメージです（AI生成）」と入れる。置き方は任せる
- 業務案内のアイコン類が要るなら、写真ではなく SVG で描く

## 2. 作るもの（7点）

| # | 置き場所 | サイズの目安 | 内容 |
|---|---|---|---|
| 1 | FV | 横長 8:3（例 2400×900） | 晴れた昼の、日本の郊外の静かな住宅街。戸建てが並ぶ道、青空。人も車もいない |
| 2 | 業務案内「売る」 | 4:3 | ごく普通の日本の2階建て戸建ての外観。手入れされた庭先 |
| 3 | 業務案内「買う」 | 4:3 | 家具の少ない、明るいリビングの室内。窓から自然光 |
| 4 | 業務案内「相続」 | 4:3 | 少し年季の入った、手入れの行き届いた日本の木造家屋と庭。落ち着いた雰囲気 |
| 5 | 業務案内「賃貸」 | 4:3 | 3階建て程度の、清潔な小規模アパートの外観 |
| 6 | 業務案内「その他」 | 4:3 | 机の上の間取り図と鍵、それを指す手元（顔は写さない） |
| 7 | 会社概要 | 4:3 | 人のいない、明るく整った小さな相談カウンター（店名・文字なし） |

業務案内の区分が企画書と変わったら、点数を合わせて増減してよい。

## 3. プロンプトの共通部分（各プロンプトの末尾に付ける）

> Realistic photograph for a typical Japanese real estate agency website. Natural daylight, clean and ordinary, not artistic. Located in Japan. No people's faces, no text, no signs, no logos, no license plates, no famous landmarks.

各画像のプロンプトは2章の「内容」を英訳したもの＋この共通部分。文言は Claude Code が整えてよい。

## 4. 生成の仕組み

- 置き場所：`tools/images/`（例 `generate.mjs` と `prompts.json`）。**プロンプトは `prompts.json` に残し、あとで同じ画像を作り直せるようにする**
- モデル：`gpt-image-2.5-flare`（OpenAI の既定の推奨）。使えなければ、使えるモデルを報告して止まる
- キー：Linux サーバーの `.env` の `OPENAI_API_KEY`（`.env` は `.gitignore` 済み）。キーの発行と `.env` への記入はユーザーが行う。手順の案内を頼む
- サイズ：カスタムサイズの制約（長辺の上限・倍数）は公式ドキュメントで確かめて合わせる
- 出力先：`/sample/` から読める場所。決め方は任せる

## 5. 進め方（2段階）

1. **FV（#1）だけを `quality: medium` で1枚**作り、ユーザーに見せる。トーンを確かめてから進む
2. ユーザーの了承後、7点を `quality: high` で作る。気に入らないものは、その番号だけ作り直す

費用の目安：high で1枚約 $0.05。作り直しを含めても $1 前後。

## 6. ユーザーにお願いすること（Claude Code から案内してほしい）

- OpenAI の管理画面で、チャットボット用とは**別のプロジェクト**（例 `RealEstate-images`）を作り、そのプロジェクトの API キーを発行する。プロジェクトの費用上限は $3 程度
- そのキーを Linux サーバーの `.env` に `OPENAI_API_KEY=` として入れる

## 7. 返してほしいもの

- 生成した画像の置き場所と、HP への組み込み結果（URL）
- 作り直しの指示を受けやすいように、番号と画像の対応表
