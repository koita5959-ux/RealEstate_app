`2026-11-04_ClaudeAI_業態モードの分け方.md` の「形態3種」について、ユーザーとの確認で次のように決まりました。（ユーザー）はユーザー本人の考えです。

## 決まったこと
- **2番（対話型）は、商品として立てない**（ユーザー）。
- 形態は **1 選択式（売り切り）** と **3 AI型（初期製作費＋月々の利用料）** の二つ。業態モード4＋1は両方に共通。
- 今の主題は変わらない：AI型 × 3番（総合系）の、相談目的〜見立てのボタン初期値とAIの返し方。

## ずれていた所
- 書面には「月額契約は API を含まず、Webページからは呼び出せない」と一行あったが、ユーザーには「店の月額AIを客の画面の対話に使える」と受け取られていた。表の「店が自分の ChatGPT／Claude で読み」だけでは、客の画面ではAIセッションにならない、という意味まで伝わらなかった。
- 確かめた事実：月額契約で言語AIと話せるのは各社の入口（claude.ai、chatgpt.com 等）だけ。プログラムからAIを呼ぶには API 契約が要る。
- そのため2番は、客の画面では1番と同じで、回答者は店の人、タイムラグが前提（LINE 公式アカウントのような形）になる。ユーザーの考える商品としては成立しない。
