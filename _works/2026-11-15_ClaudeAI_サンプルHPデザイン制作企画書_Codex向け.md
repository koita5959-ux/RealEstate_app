## 0. 最初に読んでほしいこと（いちばん大事）

あなたに頼むのは **「器」だけ** です。HTML 1枚と CSS 1枚で、見た目と文章を作ってください。

**やらないこと（ここを守れば、あとの実装でやり直しが出ません）**

- JavaScript を書かない（`<script>` を置かない）
- 送信処理・地図・チャット画面・ダミーの会話を作らない
- フレームワーク・ビルド（React、Tailwind、npm など）を使わない
- 外部の読み込み（Google Fonts、CDN、アイコンフォント、外部画像）を使わない
- リポジトリの `sample_design/` 以外のファイルに触れない（`server/`、`docs/`、`tools/` などは基幹部。読むのは自由、変更は禁止）

配線（地区名の差し込み、ボット本体の埋め込み、メール送信、記録）は、あとで Claude Code が行います。あなたは、そのための **「受け口の印」** を決まった形で置いておくだけで構いません（4章）。

## 1. 何のHPか

- 不動産業者に営業メールで送る **営業用サンプルサイト**。架空の不動産屋「AIボット不動産」の、1ページ縦長のHP
- 見た目の目標は **「どこにでもある、普通の地域の不動産屋のHP」**。凝ったデザイン、個性的な配色、尖った看板は狙わない。見た業者が「うちのHPと同じくらいだ」と感じることが正解
- このページの中に、あとから AI相談ボットが組み込まれる。業者はまず客としてボットを試し、「うちのHPにも入れたい」と思うかを判断する
- 地区（例：名古屋市・一宮市…）ごとに、同じページが「その地域の店」として見える。地区名は FV にだけ出る

## 2. 文章もボットの材料になる（書き方の注意）

このページの文章は、ただの見た目ではありません。ボットの管理機能に「HPの読み取り」があり、**このページの本文をそのまま読んで、店の情報としてAIに渡します**。

- 大事な情報は **画像の中に入れず、HTMLのテキスト** で書く
- 文章は「無難で平凡」に。売る・買う・相続・賃貸を一通り扱う、町の総合的な不動産屋として書く
- 誇大な表現（「地域No.1」「必ず高く売れる」など）は書かない
- 次の3点は、現行の読み取りで「HPに書かれていない」とされた項目なので、**必ず本文に入れる**
  1. 担当している地域（「{{REGION}}を中心に」のように、地区名の印を使って書く）
  2. 買取をどんなときにするか（例：「早く現金化したい」「古家付きで売りにくい」ときにご提案、など）
  3. 宅建の免許番号（架空。例：`○○県知事（2）第00000号`。すぐ後ろに「※サンプルのため架空の番号です」と添える）

あなたが書いた文章でボットが自然に話せるか、それ自体があとのテストになります。開発側の事情を気にせず、「よくある不動産屋の文章」を書いてください。

## 4. 受け口の印（あとで Claude Code が置き換える場所）

印は次の5種類だけ。**これ以外の仕掛けは作らない。** 印の綴りを変えないでください（文字列のまま検索して置き換えます）。

### 4-1 文字の印

| 印 | 使う場所 | 置き換え後 |
|---|---|---|
| `{{REGION}}` | FVの見出し、`<title>`、業務案内の「担当地域」の一文、会社概要の所在地 | 地区の代表の市（例「名古屋市・一宮市・春日井市」）。地区がないときは「地域」などの汎用の語 |
| `{{DEVELOPER}}` | フッター | 開発元（弊社）の名称 |

- 地区名は長くなることがある（最大で20字程度、「・」区切りで4市ほど）。FVの見出しは **長くても2行に収まり、崩れないこと**。短い場合（「札幌市」だけ）でも間が抜けないこと

### 4-2 ボットの枠（`#bot` の中）

```html
<section id="bot" data-read="skip">
  <!-- ①仕組みの説明 -->
  <!-- ②ボット本体の枠：中身は空のまま -->
  <div id="bot-slot"></div>
  <!-- ③詳しい機能説明 -->
</section>
```

- `data-read="skip"` は必ず付ける。この区画はボット自体の説明なので、HP読み取りで店の情報として読ませないための目印（読み取り側の対応は Claude Code が行う）
- `#bot-slot` は空にする。デザイン確認のため、CSSで **点線の枠と「ここにAI相談ボットが入ります」という表示**（`::before` で出す）を付けてよい
- 枠の大きさ：PCで幅いっぱい（最大960px程度）、高さの最小 640px。スマホで幅100%、高さの最小 560px。中に地図とチャットが入る想定
- ①の文案の方向：「AIボットが、お客様の土地やご事情を伺い、整理したうえで担当者へおつなぎします」程度。短く
- ③の文案の方向：地図で場所を示すだけで始められる／土地の公開データをもとに話す／24時間いつでも／最後は担当者へのお問い合わせにつながる。3〜4項目の箇条で

### 4-3 問い合わせフォーム（共通部品）

このフォームは、ページ最後の `#contact` と、ボットとの会話の終わり（あとで Claude Code が出す）の **2か所で同じものを使います**。1つの部品として、どこに置いても同じ見た目になるように作ってください。

```html
<form class="inquiry" data-inquiry>
  <!-- 項目 -->
</form>
```

- `action` も `method` も書かない。送信ボタンは `type="button"` にする
- 項目：お名前（必須）／会社名・屋号（任意）／メールアドレス（必須）／電話番号（任意）／ご質問・ご相談内容（必須、複数行）
- 送信ボタンの直前に注記：「※この見本ではお問い合わせは開発元へ届きます。御社サイトに実装したときは、御社へのメール送信に変わります。」
- 送信後のお知らせ（ポップアップ）も見た目だけ作る：

```html
<div class="inquiry-done" hidden>
  <p>メールをお預かりしました。確認後、担当者からご連絡します。</p>
  <button type="button">OK</button>
</div>
```

  `hidden` を外したときに、画面中央に重なって表示される CSS にしておく（開閉は Claude Code が付ける）

### 4-4 画像の枠

画像はまだありません（別途 OpenAI の画像APIで作る予定）。**画像を探したり作ったりせず、決まったファイル名で枠だけ作ってください。**

| ファイル名（`sample_design/img/`） | 置き場所 | 比率 |
|---|---|---|
| `01_fv.jpg` | FV背景 | 8:3 |
| `02_sell.jpg` | 業務案内・売る | 4:3 |
| `03_buy.jpg` | 業務案内・買う | 4:3 |
| `04_inherit.jpg` | 業務案内・相続 | 4:3 |
| `05_rent.jpg` | 業務案内・賃貸 | 4:3 |
| `06_other.jpg` | 業務案内・その他 | 4:3 |
| `07_company.jpg` | 会社概要 | 4:3 |

- 画像がなくても崩れないように、枠に `aspect-ratio` と薄いグレーの背景を付ける
- FVは画像の上に文字が乗るので、文字が読めるように暗めの重ね（オーバーレイ）を付ける
- 画像の近くに小さく「画像はイメージです（AI生成）」を入れる（ページに1回でよい）
- 業務案内のカードにアイコンを付けるなら、インラインの SVG で簡素に。なくてもよい

## 5. 見た目の方針

- 配色：白地＋落ち着いた1色（紺・緑・茶のどれか）＋差し色1色まで。不動産屋らしい、信頼感のある無難な色
- 文字：システムフォント（`system-ui, "Hiragino Sans", "Yu Gothic", "Noto Sans JP", sans-serif`）。本文 16px 以上、行間ゆったり
- **スマホを先に考える。** 営業メールはスマホで開かれることが多い。スマホで縦に読んで自然であること、ボタンは指で押せる大きさ
- PCでは中央寄せ、最大幅 1100px 程度
- アニメーション・パララックス・スライダーは使わない
- ヘッダーの固定（追従）はしてもしなくてもよい。する場合はスマホで画面を圧迫しない高さに
