この表について

1行＝1つの道（大分類・小分類・④・⑤）。③のボタン（HPの見出し）は「手がかりの言葉」で小分類に当て、その小分類の行から④⑤を組みます。木は持たず、行の絞り込みで組むので、⑤から逆に③④を引くこともできます。
④は「土地の種類」に入っている土地でだけ出ます（K1 家がある／K2 空き家・古い家／K3 更地／K4 駐車場・畑など）。一般語の小分類（売却など）は、具体的な小分類と同じ見出しに当たれば外します。
表の直しは Claude Code が行います（docs/data/type1_paths.csv。表計算ソフトでもそのまま開けます）。
