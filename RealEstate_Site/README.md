# RealEstate_Site — サンプルHP「AIボット不動産」

## 配色

- 深い紺 `#173B5C`：地域の不動産会社らしい信頼感の基調色
- 金茶 `#BC8A45`：見出しやロゴの控えめな差し色
- 淡い灰青 `#F4F7F8`：区画を穏やかに分ける背景色

## 配線用の印

| 印 | 配置 |
| --- | --- |
| `{{REGION}}` | title、FV見出し、業務案内の導入文、所在地 |
| `{{DEVELOPER}}` | フッターの運営・お問い合わせ先 |
| `#bot[data-read="skip"]` | AI相談区画 |
| `#bot-slot` | AI相談ボット本体の空き枠 |
| `form.inquiry[data-inquiry]` | お問い合わせフォーム |
| `.inquiry-done[hidden]` | 送信後ポップアップの見た目 |

## 制作上の判断

- モバイルで先に読みやすい一列レイアウトになり、本文はPCで最大1100pxに収まる構成です。AI相談ボットの枠だけは、PCで最大1400pxまで広げます。
- FVの地区名は長くても2行程度に収まるよう、可変の文字サイズと改行位置を設定しています。
- 当初の「画像は枠だけ」という指示は、画像を含む全体制作のご希望により更新しました。`img/` の7枚はAI生成のPNGです。
- JavaScript、外部フォント、CDN、外部画像は使用していません。

## 店舗ごとに変わる文章

- 営業時間・定休日・免許番号・所在地・電話番号
- 買取の対応範囲、売買・賃貸・管理の具体的な対応内容
- お問い合わせ先と開発元の表記
