# RealEstate_Site — サンプルHP「AIボット不動産」

## 配色

- 深い紺 `#173B5C`：地域の不動産会社らしい信頼感の基調色
- 金茶 `#BC8A45`：見出しやロゴの控えめな差し色
- 淡い灰青 `#F4F7F8`：区画を穏やかに分ける背景色

## 配線用の印

| 印 | 配置 |
| --- | --- |
| `{{REGION}}` | title、FV見出し、業務案内の導入文、所在地 |
| `{{DEVELOPER}}` | フッターの運営・お問い合わせ先 |
| `#bot[data-read="skip"]` | AI相談区画 |
| `#bot-slot` | AI相談ボット本体の空き枠 |
| `form.inquiry[data-inquiry]` | お問い合わせフォーム |
| `.inquiry-done[hidden]` | 送信後ポップアップの見た目 |

## 制作上の判断

- モバイルで先に読みやすい一列レイアウトになり、本文はPCで最大1100pxに収まる構成です。AI相談ボットの枠だけは、PCで最大1400pxまで広げます。
- FVの地区名は長くても2行程度に収まるよう、可変の文字サイズと改行位置を設定しています。
- 当初の「画像は枠だけ」という指示は、画像を含む全体制作のご希望により更新しました。`img/` の7枚はAI生成のPNGです。
- JavaScript、外部フォント、CDN、外部画像は使用していません。

## 店舗ごとに変わる文章

- 営業時間・定休日・免許番号・所在地・電話番号
- 買取の対応範囲、売買・賃貸・管理の具体的な対応内容
- お問い合わせ先と開発元の表記

## [ClaudeAI] 監修での直し（2026-11-15）

- 画像を PNG（計約18MB）から JPG（計約1.4MB）へ。カードは 1200×900、FV は元の大きさのまま。参照も `.jpg` に変更
- FV：地区名を `<span class="region" data-region-line>` に分け、小さめの1行目に。長い地区名でも市名の途中で切れず「・」で折り返す
- 業務案内：5枚目が左に寄って空きが出ていたのを、2段目を中央寄せに
- 「その他」の見出しを「買取・その他」に（本文が買取の説明のため）
- `#bot-slot` に「ここにAI相談ボットが入ります」の表示（`:empty` のときだけ出る。中身が入れば自動で消える）

## [Claude Code] 広告ページの合体（2026-11-17）

- 広告ページ（クライアント向け・ChatGPT 制作）を `pr/` に置いた。サンプルHPのヘッダー、店名の右隣の「不動産向けチャットボット セールス概要」から開く（`{{PR_URL}}`）。
- 公開の形：`/sample/?r=地区ID` がトップ、`/sample/pr/?r=地区ID` が広告ページ。どちらの index.html も api（server/sample.js）が差し込んで返し、`?r=` を引き継いで行き来する。開いた記録は sample-日付.jsonl（広告ページは page:"pr"）。
- 印の中身：`{{REGION}}`＝地区名、`{{DEVELOPER}}`＝`site.json` の developer（**開発元が個人か会社か決まったら、ここ1か所を直す**）、`{{SAMPLE_URL}}`＝トップの AI相談、`{{CONTACT_URL}}`＝トップのお問い合わせ。
- 元の zip・カンプ・企画書は _works に（2026-11-17_ClaudeAI_PRページ制作企画書_ChatGPT向け.md、2026-11-17_ユーザー_広告ページのカンプ.jpg）。
- 本番（Cloudflare 等）に移すときは、api の差し込みを静的な置き換えかページ内の小さなスクリプトに替える。
