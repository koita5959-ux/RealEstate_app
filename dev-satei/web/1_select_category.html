この表について

③のボタンはHPの言葉のまま、内部で小分類に当てます（下の「③の当て方」）。④⑤はHPの言葉ではなく、小分類と、それまでに押したボタンの言葉から、次に出す選択肢を「④⑤の候補の表」から選びます。木は持たず、文脈で次が入れ替わります（同じ選択肢が別の小分類に出ても、④と⑤に重なってもよい）。
選び方：同じ小分類の行は「重み」の順。「前の言葉」がある行は、押したボタンの言葉に当たったときだけ出して一つ上げる。別の小分類の行も、前の言葉が当たれば一つ下げて混ぜる。一度選んだものは出さない。前の段で見せて選ばれなかったものは二つ下げる。
表の直しは Claude Code が行います（dev/web/data/type1_paths.csv・type1_choices.csv。表計算ソフトでもそのまま開けます）。

選択の試し

HPのURLを入れて「分類する」と、③のボタンが並びます（URLなしでも、小分類の一覧から試せます）。③→④→⑤と押すと、次の候補が順位つきで出ます。右上の数字は点数、下の小さな字はなぜ出たかです。

③の当て方（小分類）

手がかりの言葉は上から順に当てます（上ほど細かい）。一般語の小分類（売却など）は、具体的な小分類と同じ見出しに当たれば外します。
