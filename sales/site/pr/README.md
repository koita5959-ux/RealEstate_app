# 広告ページ：カンプ準拠HTML版

2026-11-17の画像カンプ（1536 × 1024）をレイアウト基準に、独立したHTML、CSS、JavaScriptとして構成したものです。ページ全体を1枚画像にしたものではなく、テキスト、カード、見出し、CTA、FAQはHTML要素です。

- `index.html`：ページ本体、JSON-LD構造化データ、noindex
- `style.css`：PC/タブレット/スマホのレスポンシブ指定（900px、590pxの切り替え）
- `script.js`：FAQを開いた際に他のFAQを閉じる補助。JSが無効でもFAQは機能します。
- `img/`：提供された画像カンプから切り出した3枚の写真素材。**カンプに表示されていた画像を部分的に再利用しており、元画像より解像度が低い**ため本番では高解像度画像への差し替え推奨。

## 公開前の設定

`{{DEVELOPER}}`、`{{SAMPLE_URL}}`、`{{CONTACT_URL}}` を置換してください。`{{SAMPLE_URL}}` 等は未置換のままではリンク先が機能しません。

`<meta name="robots" content="noindex">` は、限定的な案内ページを想定して保持しています。SEO公開時は方針を見直してください。

カンプの配置と配色を優先し、デスクトップでは各区画を左右2カラム、スマホでは縦並びに変化させます。画像はレイアウト要素として埋め込んでおり、**画像に含まれる文字はありません**。カンプの完全なピクセル一致を保証するものではありません。
