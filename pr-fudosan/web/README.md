# セールス版（sales/web/）

サンプルHP（sales/site/、/sample/）と一緒に動く、セールス版のボットとお試し設定。2026-11-18 にプロトタイプ（当時の docs/ 直下、今の dev/web/）から写して切り離した。

- `*_main.html`：サンプルHPのボットの枠に入る画面（?embed=1。?site=bot＝サンプルHP「AIボット不動産」の初期状態、なし＝このブラウザのお試し設定）
- `*_try.html`：お試し設定（テスト利用者向けの管理画面。サンプルHPの TYPE ボタンの行き先）
- `*_report.html`：利用状況（お試し設定の「利用状況を見る」）
- `js/`・`data/`：プロトタイプの部品・データの写し。プロトタイプを直してもここは変わらない

版の運用：プロトタイプ（dev/）→ セールス版（ここ）／受注したらプロトタイプを複製して店用を始める。
サーバー（core/server/：HPの読み取り・公開データ）はプロトタイプと共有。AIへの指示は sales/prompts/ に版として持つ（2026-11-24）。
